# Legacy site archive

This folder contains the exact reachable assets captured from `leonorekingdom.xyz` before the 2026-08-03 migration. The original HTTPS certificate was already invalid at capture time, so preservation was performed before changing DNS.

The archive is deployed independently and attached to `backup.leonorekingdom.xyz`. Do not add a GitHub Pages `CNAME` file here; Cloudflare Pages owns the backup hostname and certificate.
